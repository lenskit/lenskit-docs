lenskit.data#

Data abstractions and data set access.

Submodules#

adapt

Adaptation code for dealing with legacy data layouts.

amazon

Load Amazon ratings data from Julian McAuley's group.

arrow

Arryw utility functions.

attributes

Data attribute accessors.

batches

Basic batching support.

builder

Data set builder.

checks

Data check functions for LensKit.

collection

Item list collections.

container

Data containers, the internal storage of data sets.

dataset

LensKit dataset abstraction.

entities

Entity accessors for data sets.

items

Primary item-list abstraction.

matrix

Matrix layouts.

movielens

Code to import MovieLens data sets into LensKit.

msweb

Support for the MSWeb datasets.

mtarray

Multi-format array layout.

query

Recommendation queries.

relationships

Relationship accessors for Dataset.

repr

Utility functions for implementing __str__ and __repr__ methods

schema

Pydantic models for LensKit data schemas. These models define define the data

summary

Generate summaries of datasets.

types

Basic data types used in data representations.

vocab

Vocabularies of IDs, tags, etc.
