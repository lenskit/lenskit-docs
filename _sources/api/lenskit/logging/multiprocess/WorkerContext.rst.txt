lenskit.logging.multiprocess.WorkerContext
==========================================

.. py:class:: lenskit.logging.multiprocess.WorkerContext(config, *, driver = False, zmq = None)
   :canonical: lenskit.logging.multiprocess._worker.WorkerContext

   Activate (and deactivate) a worker context.  This handles setup and teardown
   of logging, etc.

   Only one worker context can be active, regardless of how many threads are active.

   :Stability: internal
