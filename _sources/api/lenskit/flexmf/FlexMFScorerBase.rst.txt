lenskit.flexmf.FlexMFScorerBase
===============================

   :Stability: Experimental

      :type:  FlexMFConfigBase

      The component configuration object.  Component classes that support

      configuration class type, which can be a Python dataclass or a Pydantic
      model class.

   .. py:method:: to(device)

   .. py:method:: __call__(query, items)

      Generate item scores for a user.

      Note that user and items are both user and item IDs, not positions.



   .. py:method:: score_items(users, items)

      Score for users and items, after resolivng them and limiting to known
      users and items.
