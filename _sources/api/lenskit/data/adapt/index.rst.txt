.. py:function:: from_interactions_df(df, *, user_col = None, item_col = None, rating_col = None, timestamp_col = None, users = None, items = None, class_name = 'rating')

   Create a dataset from a data frame of ratings or other user-item
   interactions.

   :Stability: Caller

   :param df: The user-item interactions (e.g. ratings).  The dataset code takes
              ownership of this data frame and may modify it.
   :param user_col: The name of the user ID column.  By default, looks for columns named
                    ``user``, ``user_id``, or ``userId``, with several case variants.
   :param item_col: The name of the item ID column.  By default, looks for columns named
                    ``item``, ``item_id``, or ``itemId``, with several case variants.
   :param rating_col: The name of the rating column.
   :param timestamp_col: The name of the timestamp column.
   :param user_ids: A vocabulary of user IDs.  The data frame is subset to this set of IDs.
   :param item_ids: A vocabulary of item IDs.  The data frame is subset to this set of IDs.
   :param name: The interaction class name.

   :returns: The initiated data set.
