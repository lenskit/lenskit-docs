      :type:  Literal['tpe', 'random', 'hyperopt'] | None

      :type:  int | None

      :type:  int
      :value: 100


      The maximum number of epochs to use in iterative training.


   .. py:attribute:: min_epochs
      :type:  int
      :value: 3


      The minimum number of epochs for iterative training.


   .. py:attribute:: metric
      :type:  str | None
      :value: None


      The metric to use.

      :type:  int | None

      The length of recommendation lists to use.

      :type:  int | Literal['threads', 'backend-threads', 'all-threads']

      The number of CPUs to request from Ray Tune.


   .. py:attribute:: num_gpus
      :type:  int | float
      :value: 0


      The number of GPUs to requrest from Ray Tune.


   .. py:attribute:: checkpoint_iters
      :type:  int
      :value: 2


      The frequency for saving checkpoints.


   .. py:attribute:: error_action
      :type:  ErrorAction
      :value: 'continue'


      What to do when one of the search trials fails.

      Get the metric optimization direction.

   .. py:method:: num_search_points()
