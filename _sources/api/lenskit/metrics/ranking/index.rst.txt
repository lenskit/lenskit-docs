.. py:function:: rank_biased_precision(good, weights, normalization = 1.0)

   Compute rank-biased precision given explicit weights.

   :param good: Boolean array indicating relevant items at each position.
   :param weights: Weight for each item position (same length as good).
   :param normalization: Optional normalization factor, defaults to 1.0.

   :returns: RBP score
