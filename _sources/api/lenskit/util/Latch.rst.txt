lenskit.util.Latch
==================

.. py:class:: lenskit.util.Latch
   :canonical: lenskit.util._latch.Latch

   A thread-safe “latch” that can be tripped and reset.


   .. py:method:: is_latched()


   .. py:method:: latch()

      Latch the latch, returning ``True`` if this call took the latch, and
      ``False`` if it was already latched.



   .. py:method:: reset()

      Reset the latch.
